# 答辩现场演示剧本与故障应急清单

本剧本按 5–8 分钟本科毕业设计答辩准备。演示使用已经准备好的本地课程数据和真实服务状态；图谱、模型或消息服务不可用时，必须展示诚实的依赖故障态，不使用静态假数据代替。

## 一、演示前检查（约 30 秒）

```powershell
Set-Location 'D:/develop/PythonProject/pythonallwork/毕设/software-learning-platform'
./scripts/start.ps1 -SkipBuild
Invoke-WebRequest http://127.0.0.1:8080/actuator/health
Invoke-WebRequest http://127.0.0.1:8081/actuator/health
Invoke-WebRequest http://127.0.0.1:8082/actuator/health
```

图谱依赖单独确认：

```powershell
docker ps --format 'table {{.Names}}\t{{.Status}}'
Invoke-WebRequest http://127.0.0.1:8999/health
```

不要在演示稿或终端中输入、复制或展示任何 API Key、数据库密码、JWT 或管理员凭据。

## 三、现场应急清单

| 现象 | 快速排查 | 现场说明与兜底 |
| --- | --- | --- |
| DeepSeek/本地模型超时 | `Invoke-WebRequest http://127.0.0.1:8082/actuator/health`；检查 `software-learning-platform/logs/ai-service-*.err.log` | “当前模型依赖超时，平台保留结构化失败状态，实验不计入有效答案；我继续展示图谱、题库和评价闭环。”不要改用未记录的答案冒充结果。 |
| Python Bridge/NebulaGraph 未启动 | `Invoke-WebRequest http://127.0.0.1:8999/health`；`docker ps --format 'table {{.Names}}\t{{.Status}}'` | 在图谱页展示离线卡片；按原项目启动 Bridge 后点击重试。系统不展示静态示例图。 |
| RabbitMQ/Redis 抖动 | `Test-NetConnection 127.0.0.1 -Port 5672`；`Test-NetConnection 127.0.0.1 -Port 6379`；查看 learning-service 日志 | “消息或缓存依赖正在恢复；学习主数据仍以 MySQL 为准，推荐会在缓存失效后重新计算。”不把旧推荐快照说成实时结果。 |
| Nginx SSE 卡住 | 检查 `deploy/server/nginx-software-learning.conf` 中 `/api/` 的 `proxy_buffering off`、`X-Accel-Buffering no` 和 300 秒超时；用 `curl -N -H "Accept: text/event-stream" http://127.0.0.1:8080/api/ai/ask/stream` 检查事件是否持续到达 | “反向代理缓冲导致事件延迟，先切换到本机 5173 → Gateway 的演示链路；后续按配置检查结果修复，不宣称流式已完成。” |
| 前端或后端未启动 | `Get-NetTCPConnection -State Listen | Where-Object {$_.LocalPort -in 5173,8080,8081,8082,8999}`；查看 `logs/` | 使用本地已构建前端展示登录页和设计系统；说明真实依赖未就绪，避免把仅能打开页面误报为全链路成功。 |
| 管理员页无数据 | 确认使用具有管理员角色的测试账号；检查 `/api/admin/evaluations/summary` 的 HTTP 状态 | “管理接口按角色保护，学生账号不能越权访问；我改用已授权账号或展示接口契约与去标识化规则。”不绕过鉴权。 |

## 四、答辩边界

- 不能把 ROUGE-L、BLEU、实体召回率当作事实正确率；论文结果应结合证据覆盖和人工评分解释。
- 不能把一次 Paas 评分、一次实验或界面提示语写成“系统已经降低认知负荷”的结论。
- 不能把 RANKED 的服务端固定系统提示词、API Key、数据库密码、JWT 或模型权重展示给评委。
- 不能在外部 Mecha-QA、Python Bridge、NebulaGraph 图空间或模型权重中现场改数据；平台只调用既有只读知识服务。
