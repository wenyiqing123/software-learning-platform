## 1. 模块改动总览

### 问答与实验

- 保留 `DIRECT`、`TRIPLES`、`RANKED` 以及四种消融条件的既有 REST/SSE 契约。
- `ExperimentMetrics` 增加有效 BLEU 阶数，避免短文本被固定四阶指标误读。
- 新增服务端实验 CSV/JSON 导出：固定问题、实验类型、条件、证据顺序、耗时、模型和生成参数、提示词版本/hash、自动指标、人工评分和失败状态均可追溯。
- 导出层显式排除 `prompt` 正文；RANKED 的后台固定证据约束系统提示词不进入接口响应、导出或前端展示。
- 前端结果卡增加运行状态、成功/失败标记、证据返回顺序、分项指标和错误原因；失败条件不参与成功答案评分。

### 认知负荷与实验任务

- 新增 Flyway `V15__evaluation_order_and_delayed_measurement.sql`，为评估会话增加任务顺序和实验分配关联。
- 评估测量支持 `PRE`、`POST`、`DELAYED`、`EQUIVALENT`；任务用时由服务端会话计时保存。
- 学生端增加知情同意、任务顺序、Paas 九点语义锚点、后测和延后测验流程。
- 管理端按实验条件展示 n、均值、中位数、标准差和四分位距。
- 管理端 CSV 只导出去标识化参与者编号、条件、任务顺序、用时、Paas、测验成绩和反馈统计，不导出真实 userId。

### 前端和文档

- 管理台、评估页、实验任务页、实验工作台和导出客户端与 Wave 2 设计系统保持一致。
- 更新 `README.md`、`docs/api.md`、`docs/ui-design.md`、`docs/test-report.md`、`docs/development/continuation-ledger.md` 和路线图。
- 保留 Mecha-QA、Python Bridge、NebulaGraph 和模型权重的外部只读边界。

## 4. 建议答辩演示路径

### 学习平台主线

1. 登录学生账号，展示学习概览中的“继续上次学习、今日待复习、推荐下一步”。
2. 进入课程阅读，展示章节目录、阅读完成度、笔记、收藏和本节三个上下文入口。
3. 从本节进入知识图谱，搜索“需求分析”，展示真实节点、关系和证据抽屉。
4. 从图谱节点进入 AI 助教，选择 TRIPLES 或 RANKED，展示回答、证据和错误降级提示。
5. 进入课程练习，演示提交前题目不带标准答案，提交后展示服务端判题、解析和错因关联。
6. 进入错题整理和间隔复习，展示错题二次攻克及复习状态更新。
7. 查看可解释规则推荐和阶段性学习报告。

### 科研实验线

1. 管理员创建或开放实验任务并分配实验组。
2. 学生从实验任务进入知情同意和评估流程，确认条件与任务顺序。
3. 完成前测、问答实验、后测和 Paas 评分，必要时补录延后测验。
4. 在问答实验工作台展示 DIRECT/TRIPLES/RANKED 与四种消融的成功/失败状态、证据顺序、耗时和分项指标。
5. 管理员进入评估汇总，展示按条件统计的 n、均值、中位数、标准差和四分位距。
6. 导出匿名 CSV，说明该文件不含用户真实身份和 RANKED 固定系统提示词正文。

## Wave 4 终审补充

### 后端解耦与稳定性

- AnswerService 通过 QaStrategySelector 分发 Chat 与 Grounded RANKED 执行，保留交互式 RANKED 的 Python 原始 Prompt 兼容路径；GroundedRankedAnswer 的证据规则由 GroundedEvidenceValidator 独立承担。
- AiModelClient、AnswerStreamSession、PythonGraphClient、KnowledgeMasteryConsumer 和 Rabbit 配置均有边界测试；空模型输出、空图谱响应、非法三元组和未知 outbox 事件不会被当作成功。

### 安全与数据隔离

- QuizService 的学生题目投影测试确认 answer 和 answerJson 不会在提交前返回；错题变更测试确认查询带 user_id 归属条件。
- 管理员接口继续使用 ADMIN 方法级鉴权；课程进度、笔记、错题、复习、推荐、会话、报告、评估和实验记录沿用当前令牌用户查询。仓库扫描未发现真实 API key、数据库密码、私钥或模型权重。

### 管理台收口

- Admin、AdminDiagnosis、QuestionBank、MicroLessonAdmin、MicroLesson、TeachingDashboard、LearningReport 统一使用设计 token 和 FeedbackState；停用、发布操作有二次确认，题库导入限制 2MB JSON，加载/空数据/错误状态均可重试或给出行动提示。
